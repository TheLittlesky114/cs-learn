# C# 学习笔记库（Lesson 1–20）

一个用于 **C# 语言入门学习** 的代码仓库，以「一节课一个可运行的控制台项目」的形式，把语法知识点拆成 20 个独立示例。
每个项目都按知识点用 `#region` 分段，配有大量中文注释与课后练习题，适合边读代码边运行验证。

- **语言 / 平台**：C# / .NET 10.0（`net10.0`），控制台应用（`OutputType=Exe`）
- **项目数量**：20 个独立 `.csproj`，统一由 `c#学习.slnx` 解决方案组织
- **代码规模**：约 2,800 行，全部为 `Program.cs` 单文件示例
- **用途**：个人学习记录、语法查阅、教学演示

## 运行方式

### 方式一：命令行（.NET SDK）

需要安装 **.NET 10.0 SDK**。

```bash
# 运行某一课，例如第 20 课
dotnet run --project "Lesson20循环语句for/Lesson20循环语句for.csproj"

# 含空格的项目路径需要加引号
dotnet run --project "Lesson19循环语句do while/Lesson19循环语句do while.csproj"

# 还原 / 编译整个解决方案
dotnet build "c#学习.slnx"
```

### 方式二：Visual Studio

直接用 Visual Studio（支持 `.slnx` 的版本）打开根目录下的 `c#学习.slnx`，在解决方案资源管理器中把某一课设为启动项目后按 F5 运行。

## 代码约定

- 每个示例都在 `Main` 中用 `#region 知识点一 / 知识点二 …` 划分段落，注释写在对应代码上方；
- 被注释掉的代码通常是「反例」或「错误写法演示」，用于说明语法限制；
- 多数课程文件末尾有 `#region 练习题`，为配套练习；
- 课程之间存在递进关系，建议按编号顺序阅读。

## 仓库说明

- 已通过 `.gitignore` 排除构建产物与本地环境文件：`bin/`、`obj/`、`.vs/`、`Library/`、`Temp/`、`*.dll`、`*.exe`、`*.pdb`、`*.cache`、`*.db`、`*.user`、`*.suo` 等；
- 仓库中 **不包含任何令牌、密钥、密码或连接字符串**。示例代码里出现的 `"小明"`/`"666"`、`"admin"`/`"8888"` 等，均为讲解登录逻辑时使用的**虚构演示数据**，与真实凭据无关；
- 本项目仅用于学习记录，代码以「把语法讲清楚」为目标，未做工程化封装与生产级设计。
